# Website-SENAI


## Website SENAI - Curso de Automotiva

Este foi um projeto feito em sala de aula, na matéria de Linguagem de Marcação (LIMA), em que a equipe devia desenvolver um website de divulgação para o curso de Automotiva da escola SENAI Prof. Vicente Amato - Jandira.


## Sobre o projeto

O site apresenta de forma sucinta o curso para quem quer conhecer a área automotiva, com foco em explicações do que é o curso, quanto tempo dura, quais matérias estudam, quem são os professores e que certificação o aluno recebe!

Na escolha da estrutura, o site foi pensado com a ideia de mobile-first e depois para telas de iPad e Desktop:

- Celular: 320px | Todas as telas 
- iPad Mini: A partir de 768px 
- Desktop: A partir de 1024px 


## Tecnologias utilizadas

- **HTML5**: para a estrutura das páginas (`header`, `main`, `section`, `footer`);
- **CSS3**: estilização com flexbox e media queries;
- **Google Fonts**: fonte Montserrat;
- **Figma**: protótipos das telas;
- **Git e GitHub**: versionamento e trabalho em equipe.
